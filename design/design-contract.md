## 二、字阶（1920 基准 → Flutter 960dp 折算）

| 层级 | 稿内 px | Flutter sp | 字重 | 行高 | 用途 |
|---|---|---|---|---|---|

| 屏标题 H1 | 56 | 28 | 800 | 1.16 | 详情页剧名 |
| 区块标题 H2 | 32 | 16 | 800 | 1.1 | 「继续观看」「今日热榜」 |
| 播放器标题 | 40 | 20 | 800 | 1.2 | OSD 剧名 |

## 三、形状与密度

- 圆角仅两档：卡片/缩略图 `12px`、按钮与徽标 `999px`（pill）。面板 `16px` 属第三档 → **落地时统一收成 12px**，详见「待确认」。
- 间距基数 4；常用 6 / 10 / 12 / 16 / 18 / 22。
- 密度：**宽卡横排**，缩略图 `300×169`（16:9），一屏 5 张完整 + 半张露出（暗示可滚动）。
- overscan 安全区：上 34 / 下 56 / 左右 72（1080p 电视普遍 3–5% 裁边）。

## 四、组件规范

### 左侧导航（浮动玻璃）
- 收起宽 `118px`（仅图标 26px + 10px 标签）；任一子项获焦 → 整栏展开到 `300px`，图标 + 18px 文字。
- 材质：`linear-gradient(180deg, rgba(12,14,19,.90), rgba(8,9,12,.62))` + `backdrop-filter: blur(18px)`。
- 选中（当前 tab）：珊瑚色图标 + `--brand-dim` 胶囊底 + 无左侧竖条（去掉 Material 的 indicator）。
- 焦点：整块反色（白底 + 黑图标），`scale(1.04)`。
- 底部「设置」用 `margin-top:auto` 贴底，与主功能区分隔。

### 卡片（核心焦点单元）
| 状态 | 表现 |
|---|---|
| 默认 | `brightness(.70) saturate(.86)`，无边框 |
| 焦点 | `scale(1.065) translateY(-5px)`、`brightness(1.1)`、3px 白环 + 8px 白晕(`.14`) + `0 30px 64px -16px` 黑投影 + 90px 珊瑚外发光 |
| 焦点同排其他卡 | 保持默认（仅整体行 `dim` 到 `.34`） |
| 其他行 | 整行 `opacity:.34` |

> **焦点必须同时满足三重可辨**：缩放 + 白环 + 提亮。客厅远距离单一手段不够。

### 按钮
- 主：珊瑚实心 + 珊瑚投影，高 `62px`，pill。
- 次：`rgba(255,255,255,.10)` + `1px` 白边 + 毛玻璃。
- 焦点：整体反白（白底黑字黑图标）+ 3px 白环 + `scale(1.045)`。**不做描边高亮**——反白在 3m 外辨识度最高。

### 选集格
- **12 列**网格（24 集正好 2 行），单格 `62px` 高、宽约 `104px`，圆角 9px；状态：已看（灰字）/ 正在看（珊瑚底+珊瑚字+「正在看」）/ 未看（灰底+时长）。
- 焦点：白底黑字 + `scale(1.07)` + 3px 白环 + 白晕。

### 详情页推荐行
- 小卡 `220×124`（同 16:9），间距 `16px`，标题 17px、副标题 14px；视觉与首页卡一致，可获焦。

### 播放器 OSD
- 顶部条：返回按钮 + 快进快退提示；底部条：剧名 / 进度条（缓冲层 + 播放层 + 可拖圆钮）/ 控制按钮组。
- 中间大播放键 `86px` 白圆实心，两侧 `66px` 半透明。
- **大播放键获焦不能用白环**（它本身是白底，白环不可见）→ 改用 `4px 珊瑚实环 + 5px 淡晕 + 48px 柔和外发光`。这是全站唯一的例外，务必在代码里单独处理。
- 进度条高 `8px`（TV 上 4px 看不见），拖拽圆钮 `22px`，获焦放大 1.18 并加双环。
- 底部 OSD 高约 `340px`，`linear-gradient(transparent → rgba(0,0,0,.94))`，不做整块黑底。

## 五、焦点导航模型（遥控器映射）

```
D-pad ← → ↑ ↓      在同一行内左右移动 / 上下换行
OK (Enter)          进入详情 / 播放 / 激活按钮
Back (Esc)          关闭 OSD → 返回上一级 → 首页
```

导航图：

```
首页    [左侧导航] ⇄ [Hero 按钮] ⇄ [内容行 0 卡片 0..n]
                          ⇅              ⇅
                     [内容行 0]     [内容行 1 卡片 0..n]

详情     [操作按钮组] ⇅ [正序/倒序] ⇅ [选集 12列×2行] ⇅ [推荐行 卡片 0..n]
```

- 卡片行按 `←` 到最左再按一次 → 跳到左侧导航（TV 通用约定）。
- 行内 `↑` 到第一行再按 → 跳到 Hero 按钮；`↓` 到最后一行为止，不循环。
- **不做焦点陷阱**：任何位置连续 `Back` 都能回首页。
- 播放页方向键直接快退/快进 10 秒（不弹 OSD），任意键唤出 OSD。

## 六、每屏结构与视觉层级

### 首页
```
┌─ 左侧玻璃导航 118/300 ─┬─ Hero（400px 高）───────────────┐
│  发现（选中）           │  眉标胶囊「正在热播 · 全76集」    │
│  追剧                  │  剧名 64px/800（本屏最大）      │
│  最近                  │  评分·年份·类型·集长·标签       │
│  下载                  │  简介 2 行                      │
│  ─────                │  [继续观看·第3集] [加入追剧]     │
│  设置                  │  进度条 12:38/22:05            │
│                        ├─ 内容行「继续观看」──────────────┤
│                        │  5 张宽卡 + 半张露出            │
│                        ├─ 内容行「今日热榜 TOP10」─────────┤
│                        │  5 张宽卡 + 半张露出            │
└───────────────────────┴─ 遥控提示条（左下）──────────────┘
```
层级声明：**1. 剧名（64px）→ 2. 卡片焦点（白环+发光）→ 3. 行标题（32px）→ 4. 元信息**。Hero 只放一部主推 —— TV 首页不做信息密集，一屏只回答「接着看什么」。

### 详情页
海报（300×400）+ 右侧信息列；操作按钮横排；选集面板贴底。层级：**剧名 > 主 CTA（从第 N 集继续）> 选集格**。面包屑保留但压到 15px 弱色，不抢焦点。

### 播放页
画面占满全屏，OSD 只在操作时出现；底部 OSD 从下往上依次：剧名/集信息 → 进度条 → 控制组。**进度条是唯一视觉重心**，按钮退到次要。

## 七、默认项与推断声明

| 项 | 状态 | 说明 |
|---|---|---|
| 深色为唯一主题 | 推断 ▲ | 客厅暗光环境 + 电视系统级惯例（Netflix/爱奇艺/Disney+ TV 均为深色）。原 App 有浅色主题，TV 端建议丢弃 |
| 横版 16:9 缩略图 | 推断 ▲ | 原 App 用竖版海报。TV 一屏只能放 3 张竖版，横版可放 6 张且远距可辨 |
| 品牌珊瑚橙保留 | 沿用 | 用户产品既有品牌资产，仅提亮 |
| 字体 | 系统栈 | 无商用授权字体，`-apple-system → PingFang SC → Microsoft YaHei → Noto Sans SC` |
| 海报画面 | 占位 | 全部 CSS 渐变 + 剪影生成，**非真实海报**，落地接真实封面 URL |
| 剧名与简介 | 占位 | 按短剧真实命名风格编的示例文案，非真实片库 |
| 选集 9 列 / 24 集 | 推断 ▲ | 按 1080p 宽度估算；集数多时改分页 |
| 无在线字体 / 无外网图片 | 约束 | 完全离线可打开 |

## 八、Flutter 落地映射（确认设计后执行）

| 设计概念 | Flutter 实现 |
|---|---|
| 焦点三重可辨 | `Focus` + `AnimatedScale` + `AnimatedContainer(boxShadow)` + `ColorFiltered(brightness)` |
| 左侧导航展开 | `AnimatedContainer(width:)` 由 `Focus` 状态驱动 |
| 卡片行 | `ListView(scrollDirection: horizontal)` + `ensureVisible` 自动滚动 |
| 焦点跨行 | 用 `FocusTraversalGroup` + `OrderedTraversalPolicy`，或显式 `onKeyEvent` 接管方向键 |
| 非焦点降亮度 | `ColorFilter.matrix` 或 `Opacity`（`Opacity` 更省，但会丢发光，建议 `ColorFiltered`） |
| 播放 OSD 进度条 | 现有 `player_controls.dart` 改造：高度 4→8dp，圆钮 22dp，加缓冲层 |
| 字号 | `textScaler` 统一按 960dp 基准 ×0.5 |

**建议改造范围**：`app_theme.dart`（整份换 token）+ `app_layout.dart`（`televisionTheme` 换成焦点三重可辨）+ `home_screen.dart`（拆掉 AppBar，改浮动导航 + Hero + 横向行）+ `detail_screen.dart` + `player_controls.dart`。`widgets.dart` / `remote_widgets.dart` 里的按钮与卡片按新 token 重做。
