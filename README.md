# 真果TV

> **Android TV 短剧应用**：遥控器全流程操作，装在电视上就能刷剧。
>
> 基于开源项目 guoapp（原作者：鱼佬）改造的电视专用版本，非官方、非商业，仅供个人学习与自用。

真果TV 是为 **电视大屏 + 遥控器** 重新打磨的短剧应用：横屏锁定、电视桌面入口、焦点全程可视、遥控器返回键防误退、搜索支持拼音输入法与首字母联想。站源的请求、解析与播放全部在设备本地完成，不依赖任何自建服务器。

**当前状态：基础使用已完全跑通** —— 在 TCL Android 11 电视（armeabi-v7a）实机验收通过，首页浏览、搜索、播放、返回、下载、追剧等主流程均正常。

## 一个应用

| 应用名 | 包名 | 站源 |
| --- | --- | --- |
| 真果TV | `com.duanju.zhenguo.tv` | 红果、韩小圈、鬼片、青空，以及黄豆、剧果、野果、帝果、黄果视频、黄果 AI、黄果旧版 |

- 电视端只发布这一个应用，全部站源已内置，不需要再选版本。
- 默认可见站源（红果、韩小圈、鬼片、青空）无需密码；其余站源默认隐藏，在站源管理中通过密码锁解锁后显示。
- 包名与历史上的「红果鉴 TV」（`com.duanju.duanju_app.tv`）、「真果鉴 TV」（`com.duanju.zhenguojian.tv`）都不同，**三者可以同时安装、互不覆盖**；装好后旧版要不要卸载由你决定。
- 因为是新包名，**旧版的追剧记录、搜索历史不会带过来**。

## 电视端特性

| 特性 | 说明 |
| --- | --- |
| 遥控器全流程 | 方向键移动焦点、确认键激活、菜单键呼出更多操作，不依赖触屏 |
| 焦点可视 | 全应用统一焦点高亮（描边 + 底色），滚动容器内自动跟随滚动，10-foot 视距可辨 |
| 返回键分层 | 播放中返回 → 回到剧集目录；目录页返回 → 底部提示「再按一次返回键退出应用」，2 秒内再按才退出，防误触 |
| 拼音输入搜索 | 搜索框聚焦自动弹出系统拼音输入法（搜狗 TV 版），可打全拼精确输入剧名；也可用左侧字母键盘按首字母联想 |
| 播放内核 | 电视端使用 media_kit / libmpv 解码，支持红果的 CENC 加密流（ExoPlayer 系无法传解密密钥） |
| 亮度交给电视 | 播放页不接管屏幕亮度，交由电视系统与遥控器管理 |
| 电视桌面入口 | 仅出现在电视桌面（LEANBACK），横屏锁定，独立电视横幅 |

### 网络与资源设置

管理员从「设置与备份 → 网络与资源」选择自动、直连或手动代理，手动地址支持 HTTP、HTTPS、SOCKS5 / SOCKS5h。代理地址默认遮蔽、不进入备份；设备内播放服务始终绕过代理。自动模式读取系统静态代理与排除列表，恢复前台及每 30 秒更新；代理不会关闭 TLS 校验。

目录请求并发可设 1–6、间隔 0–5000 毫秒（默认 3 / 250ms）；下载并发默认 2、可设 1–6。

### 局域网互联：追剧同步与推送播放

两台设备在同一局域网直连，自动同步追剧记录或接续播放，不依赖账号服务器。服务类型 `_zgj-link._tcp`（DNS-SD / mDNS），首次配对记录证书指纹。

入口：「追剧 → 标题栏同步」或「设置与备份 → 设备互联」。

## 安装

| 平台 | 说明 |
| --- | --- |
| Android TV（主线） | 三架构 APK（arm64-v8a / armeabi-v7a / x86_64），按电视 CPU 选择；已装同名包可覆盖升级，数据保留 |
| Android 手机 / 平板 | 仍保留手机版构建（包名不带 `.tv`），非本次主线 |
| Windows / iOS | 源码保留相关工程，未随电视版验收 |

- 电视安装：U 盘拷入 APK，用电视自带的文件管理器安装。注意部分电视会自动清理下载目录里的 APK，建议装完即删或直接 U 盘安装。
- `INSTALL_FAILED_NO_MATCHING_ABIS` 表示 APK 与设备架构不匹配，换对应架构的包即可。
- 部分电视会拦截 adb 安装（`INSTALL_FAILED_VERIFICATION_FAILURE`），走文件管理器手装即可。

## 构建

Flutter `3.47.4`、Dart `3.12+`、Go `1.24.1+`、Python `3.10+`。Android 需要 JDK 17、SDK 36、NDK `28.2.13676358`。

~~~sh
python3 scripts/build_android.py --flavor tv                  # 真果TV（电视版，固定全站源）
python3 scripts/build_android.py --flavor tv --abi arm64-v8a
python3 scripts/build_android.py --flavor tv --cn-mirrors     # 国内镜像
~~~

手机上调试电视版：`flutter run --flavor tv --dart-define=TV_BUILD=true`（需先 `python3 scripts/build_native.py --platform android --abi <架构>` 编译核心）。

### GitHub Actions

推送 `main` / `master`、`v*` 标签、提交 PR，或手动运行 **Build app packages**，自动构建 2 个变体：

| 产物 | 内容 |
| --- | --- |
| `zhenguojian-tv-android` | 电视版「真果TV」三种架构 APK 和 SHA256 |
| `zhenguojian-android` | 手机版三种架构 APK 和 SHA256 |

Android 正式发布使用同一签名并递增构建号，在仓库 Secrets 配置：`ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`。未配置时生成 debug 签名预览包。

本地不入库的 `android/key.properties`：

~~~properties
storeFile=/absolute/path/zhenguojian-release.jks
storePassword=你的密码
keyAlias=zhenguojian
keyPassword=你的密码
~~~

## 开发约定

站源是 Go 原生 provider（`native/core/provider_*.go`），不是运行期加载的脚本。新增站源需接入：`provider_huangguo.go`（常量 / 白名单 / 来源规范化 / 分集接口）、`provider_media.go`（baseURL / host 反查 / 播放分派）、`app_categories.go`、`app_cover_metadata.go`、`app_runtime.go`（目录 / 搜索 / 详情分派 + 空页放行），并在 `lib/models.dart` 登记 `SourceSite`。

电视端注意：

- 新增页面必须保证遥控器焦点可达：滚动容器包 `TelevisionFocusScroller`，列表项用 `TvTile` / `RemoteTarget` 壳。
- 不要用裸 `TextField` 在电视上弹系统键盘（搜索框除外——那里需要拼音输入法）；表单输入走自建键盘组件。
- 返回逻辑统一走 `PopScope` + 全局返回处理，不要在页面里直接 `Navigator.pop` 或 `SystemNavigator.pop`。
